# AI 리터러시 드릴

생성형 AI·ML 개념부터 **AI가 낸 결과를 검증하는 판단력**까지 연습하는 문제 사이트입니다.
설치도 로그인도 없이 브라우저에서 바로 풉니다.

**→ https://haweee47.github.io/ai-literacy-drill/**

## 담긴 것

- **155문항** — 생성형 AI·LLM, RAG·파인튜닝, 프롬프트, ML 지표, 딥러닝, 데이터 검증 설계,
  AI 윤리·보안, AI 반도체(HBM·메모리 병목), 제조 AI
- **긴 지문 세트 8개** — 상황 설명·표·AI 출력물·로그·쿼리를 읽고 3~4문항씩 판단합니다
  (설비 알림 요약 도구, 사내 규정 챗봇, 프롬프트 A/B 비교, AI가 짠 분석 쿼리, 수율 예측 모델 검토 등)
- **실전 모드** — 20문항 30분(개념형) / 16문항 90분(지문형). 제출 전에는 정답을 보여주지 않습니다
- **문항마다 해설** — 왜 그게 답인지, 어디서 헷갈리는지
- 보기 순서와 문제 순서는 매번 섞이고, 헷갈린 문제 표시·약점 분석·실전 기록을 지원합니다

풀이 기록은 브라우저(localStorage)에만 저장되고 어디로도 전송되지 않습니다.

## 만들기

원본은 `../ai_해커톤/drill.html` 하나입니다. 공개용 `index.html` 은 거기에 HTML 머리말과
링크 미리보기 메타를 붙여 만듭니다.

```bash
python tools/build.py      # index.html 생성
```

`og.png` 는 `tools/og.html` 을 1200×630 으로 캡처한 링크 미리보기 이미지입니다.
